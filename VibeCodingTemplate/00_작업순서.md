# 기본 작업 절차

## 원칙

- 대상은 개인용 Python·Qt·PC·Android·알고리즘 프로젝트(약 10,000줄 이하)로 한다.
- 문서는 구현에 필요한 사실만 기록하고, 같은 내용은 한 파일에만 둔다.
- 기초 문서를 확정한 뒤 MVP 전체를 한 번의 구현 요청으로 작성하고 검증한다.
- 질문·설계·문서 작성 자체가 목적이 되지 않도록, 이미 정해진 내용은 다시 묻지 않는다.
- AI의 설명보다 실행한 코드와 테스트 결과를 기준으로 완료 여부를 판단한다.

## 문서별 기준 정보

| 파일 | 기록할 내용 |
|---|---|
| `01_프로그램기능.md` | 사용자가 원하는 동작, 범위, 완료 조건 |
| `02_결정사항들.md` | 초기 질문 과정에서 확정한 결정과 가정 |
| `AGENTS.md` | 이 저장소에서 항상 지킬 작업 규칙 |
| `docs/DESIGN.md` | 현재 구조, 데이터 흐름, 주요 인터페이스 |
| `docs/DECISIONS.md` | 구현 중 확정한 중요 결정과 이유 |
| `docs/TODO.md` | MVP 전체 구현 체크리스트와 완료 조건 |
| `docs/tasks/*.md` | 개별 변경 요청, 재현 방법, 검증 결과 |

## 1. 요구사항 작성

`01_프로그램기능.md`에 MVP 기능과 완료 조건을 작성한다. 제외 범위와 실행 환경도 결과에 영향을 줄 때만 적는다.

## 2. 구현을 막는 결정 확인

`10_보완질문요청.md`를 AI에 전달하고 답을 정해 `02_결정사항들.md`에 기록한다.

다음 경우에만 `11_보완질문요청.md`로 한 번 더 확인한다.

- 첫 답변 뒤에도 미결 항목이 남은 경우
- 요구사항이 크게 바뀐 경우
- 보안, 데이터 손실, 배포처럼 되돌리기 어려운 결정이 있는 경우

일반적인 개인 프로젝트는 AI 하나의 검토로 충분하다. 서로 다른 AI의 교차 검토는 위험이 크거나 답이 충돌할 때만 한다.

## 3. 최소 기초 문서 생성

`20_기초문서작성요청.md`로 `AGENTS.md`, `docs/DESIGN.md`, `docs/DECISIONS.md`, `docs/TODO.md`를 만든다.

생성 이후의 결정 기준 문서는 `docs/DECISIONS.md`다. `02_결정사항들.md`는 초기 인터뷰 기록으로 보존하되 두 파일을 계속 중복 갱신하지 않는다.

## 4. MVP 전체 구현 및 검증

`30_구현요청.md`로 `docs/TODO.md`의 MVP 항목 전체를 한 번에 구현한다. AI는 내부적으로 의존 순서에 따라 작업하되, 각 항목마다 사용자 확인을 기다리지 않고 구현과 검증을 계속한다.

한 번의 요청에서 다음 순서까지 수행한다.

1. 관련 코드와 문서를 확인한다.
2. MVP 전체를 의존 순서에 따라 구현한다.
3. 자동 테스트, 빌드 또는 가능한 수동 검증을 실행한다.
4. 실패한 검증은 원인을 수정하고 다시 실행한다.
5. 각 완료 조건과 실제 결과를 대조한다.
6. 실제 구조나 결정이 달라진 경우에만 관련 문서를 갱신한다.
7. 완료 항목을 TODO에서 정리하고, 미완료 항목이 있으면 원인과 남은 작업을 명확히 기록한다.

치명적인 미결정 사항, 접근 권한 부족, 외부 장비 부재처럼 진행할 수 없는 사유가 없다면 중간 단계에서 멈추거나 추가 승인을 요청하지 않는다.

## 5. 수정 요청

`docs/tasks/ChangeRequest.md`는 이름을 바꾸지 않고 원본 템플릿으로 유지한다. 수정할 때 템플릿을 복사해 `001_간단한제목.md`, `002_간단한제목.md`처럼 만든다.

수정 요청에는 현상, 기대 동작, 재현 방법, 완료 조건만 우선 기록한다. 수정 후에는 관련 테스트를 다시 실행하고, 실제 설계나 중요 결정이 바뀐 경우에만 `DESIGN.md` 또는 `DECISIONS.md`를 갱신한다.

## 6. 완료 기준

- `01_프로그램기능.md`의 MVP 완료 조건을 만족한다.
- 관련 테스트·빌드·수동 확인이 통과한다.
- 알려진 제한이나 남은 작업이 `docs/TODO.md`에 짧게 기록되어 있다.
- 실행 방법이 별도 설명 없이는 불명확한 경우에만 README에 실행 방법을 남긴다.
