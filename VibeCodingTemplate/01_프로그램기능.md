# 프로그램 기능

## 목표

대면스터디에서 활용할 퀴즈 생성 프로그램을 만들고싶다. 팀원들이 AI 트렌드에 관한 정보글을 올리면 매 스터디 세션마다 저번 스터디 이후 ~ 이번 스터디 이전까지 올라온 정보글들을 바탕으로 간단 퀴즈를 생성한다.


## 실행 환경

- 노션
- 깃허브 구조
main/
├─ session01/
│  ├─ (임의의 제목).md
│  ├─ (임의의 제목)md
│  └─ (임의의 제목).md
│
├─ session02/
│  ├─ (임의의 제목).md
│  └─ (임의의 제목).md
│
└─ session03/

## MVP 기능과 완료 조건

1. 노션 DB와 깃허브를 연동해 자동 커밋 기능
   - 완료 조건: 노션 DB에 사용자들이 글을 올리는데, 동기화 버튼을 누르면 그것들이 깃허브 레포에 내가 지정한 폴더 위치에 자동으로 마크다운 파일 형식으로 커밋된다.
2. AI가 깃허브 session별로 퀴즈 생성해주는 기능
   - 완료 조건: session별로 퀴즈가 생성된다. 난이도는 session 내 글들을 읽었으면 대체로 쉽게 풀 수 있는 수준으로. 약 20문제 내외, 4지선다.
