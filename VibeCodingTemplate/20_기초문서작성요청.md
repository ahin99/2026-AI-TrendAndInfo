# 기초 문서 작성 요청

## 입력 문서

- 현재 폴더 아래에 있는 `01_프로그램기능.md`
- 현재 폴더 아래에 있는 `02_결정사항들.md`

## 요청사항

저장소의 기존 코드와 문서를 먼저 확인한 뒤, 아래 파일을 새로 만들거나 현재 상태에 맞게 수정해줘.

- `AGENTS.md`: 저장소에서 항상 지켜야 할 빌드·테스트·코딩 규칙
- `docs/DESIGN.md`: 현재 구조, 핵심 데이터 흐름, 상태, 주요 인터페이스, 오류 처리
- `docs/DECISIONS.md`: 확정된 중요 결정, 이유, 영향
- `docs/TODO.md`: MVP 전체 구현 체크리스트와 각 항목의 검증 가능한 완료 조건

## 작성 규칙

- 약 10,000줄 이하의 개인 프로젝트에 맞게 꼭 필요한 내용만 작성해.
- 같은 사실은 한 문서에서만 설명하고 다른 문서에서는 링크나 파일명으로 참조해.
- 일반적인 개발 상식이나 AI 사용법은 `AGENTS.md`에 넣지 말고, 이 저장소에 특화된 규칙만 넣어.
- `AGENTS.md`에는 별도 요청이 없는 한 MVP 전체를 한 번에 구현·검증하고, 중간 작업별 승인을 기다리지 않는다는 작업 방식을 포함해.
- `DESIGN.md`는 목표가 아니라 실제로 채택한 구조를 기록해. 아직 구현 전인 내용은 `계획` 또는 `가정`으로 표시해.
- 현재 폴더 아래에 있는 파일 중 `02_결정사항들.md`의 확정된 중요 결정은 `docs/DECISIONS.md`로 옮기고, 이후 그 파일을 기준 정보로 사용한다고 명시해.
- `TODO.md`는 한 번의 구현 요청으로 전체를 수행할 수 있도록 의존 순서대로 정리해. AI의 내부 작업 순서를 위한 항목 구분은 허용하지만 단계별 사용자 요청을 전제로 나누지 마.
- 필수 구현, 통합 검증, 후순위 항목을 구분해. MVP 전체 구현 요청에는 필수 구현과 통합 검증을 모두 포함해.
- 완료 작업의 긴 이력을 TODO에 쌓지 마. 추적할 필요가 없으면 제거하고, 필요하면 한 줄로 축약해.
- MVP 밖의 작업은 `후순위`에 분리해.
- 사용자가 정하지 않은 제품 기능을 추가하지 마. 불가피한 가정은 명시해.
- AGENTS.md의 작업 진행 원칙 이란 항목에 다음을 추가해줘
  - 사소한 선택사항이나 구현 세부사항은 질문하지 말고 합리적으로 판단하여 계속
    진행한다.
  - 작업을 막는 중요한 모호성이 있거나 샌드박스 밖 접근 등 추가 권한 승인이
    필요한 경우에만 질문한다.
