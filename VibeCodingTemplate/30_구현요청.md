# 구현 요청

## 참고 문서

- `AGENTS.md`
- `docs/DESIGN.md`
- `docs/DECISIONS.md`
- `docs/TODO.md`

## 요청사항

저장소의 현재 코드와 변경 상태를 먼저 확인하고, `docs/TODO.md`에 있는 **MVP 전체를 한 번에 구현하고 검증해줘**. 의존 관계에 따른 내부 작업 순서는 스스로 정하되, 항목 하나가 끝날 때마다 멈추거나 사용자 확인을 요청하지 말고 전체 완료를 목표로 계속 진행해.

- 기존 사용자 변경을 보존해.
- 요구사항에 없는 기능이나 대규모 리팩터링을 추가하지 마.
- 프로젝트에 이미 있는 패턴과 도구를 우선 사용해.
- 임시 골격이나 일부 기능만 만든 상태에서 완료로 판단하지 마.
- 전체 기능을 연결한 뒤 관련 테스트·빌드·정적 검사를 실행해.
- 검증 실패는 가능한 범위에서 원인을 수정하고 다시 실행해.
- 자동 검증이 불가능하면 재현 가능한 수동 확인 절차를 제시해.
- 실제 구조나 중요 결정이 바뀐 경우에만 `DESIGN.md` 또는 `DECISIONS.md`를 갱신해.
- 모든 완료 조건을 만족하면 `TODO.md`를 정리해. 일부를 끝내지 못하면 완료한 범위, 남은 조건, 진행할 수 없었던 원인을 기록해.
- 치명적인 미결정 사항, 권한 부족, 필요한 외부 자원 부재가 아니면 중간 확인을 요청하지 마. 합리적인 기본값으로 진행하고 결과에 영향을 주는 가정만 기록해.

작업 결과에는 전체 구현 여부, 변경한 내용, 검증 결과, 남은 문제만 간결하게 알려줘.
