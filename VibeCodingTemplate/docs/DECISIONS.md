# 결정 기록

이 파일은 기초 문서 생성 이후 중요 결정과 구현 가정의 기준 정보다. `02_결정사항들.md`는 초기 인터뷰 기록으로 보존하며 이후 중복 갱신하지 않는다.

## 확정된 중요 결정

`02_결정사항들.md`에는 사용자가 확정한 답이 없었다. 다음은 MVP 구현 과정에서 실제 인터페이스를 고정하기 위해 채택한 기술 결정이다.

| ID | 결정 | 이유와 영향 |
|---|---|---|
| D-001 | 노션 연동은 `Notion-Version: 2025-09-03`의 database/data source API를 사용한다. | 현재 API의 database와 data source 분리를 반영한다. database에 데이터 소스가 여러 개면 자동 선택하지 않고 ID를 요구한다. |
| D-002 | 퀴즈 생성은 OpenAI Responses API의 strict JSON Schema 구조화 출력을 사용한다. | 문제 형식을 API 단계와 로컬 검증 단계에서 함께 제한한다. 설정한 API base가 이 인터페이스와 호환되어야 한다. |

아래 항목은 답이 없을 때 적용한 가정이며 사용자 결정으로 간주하지 않는다.

## 구현 가정

| ID | 가정 | 이유와 영향 | 다시 확인할 때 |
|---|---|---|---|
| A-001 | GitHub Actions의 수동 실행에서 session 번호를 필수로 받고, 노션 동기화와 퀴즈 생성을 별도 워크플로로 실행한다. | 별도 서버·UI 없이 각 실패 단계만 재실행할 수 있다. | 사용자가 다른 실행 UI나 자동 연계를 요구할 때 |
| A-002 | 노션 속성 기본값은 `Name`, `Session`, `Status`, 게시 상태 값은 `Published`로 하고 환경변수로 바꿀 수 있게 한다. 제목과 텍스트 본문만 동기화하며 이미지·첨부는 원본 노션 링크를 남긴다. | 날짜 경계 대신 명시적 session을 사용하며 DB별 이름 차이를 수용한다. | 실제 노션 DB 스키마로 연동할 때 |
| A-003 | 노션 페이지 ID로 같은 글을 찾아 멱등 갱신한다. 노션에서 사라진 글은 자동 삭제하지 않고, 동기화 후 사용자가 수정한 파일은 덮어쓰지 않는다. | 중복과 예기치 않은 데이터 손실을 방지한다. | 삭제 동기화나 GitHub 직접 편집 정책이 필요할 때 |
| A-004 | `quiz.md`에는 최대 20개의 4지선다 문제를, `quiz_answers.md`에는 정답·짧은 해설·근거 글 링크를 저장한다. 근거가 부족하면 문제 수를 줄인다. | 진행 중 정답 노출과 환각을 줄인다. 두 파일은 모두 성공한 뒤 함께 교체한다. | 문제 형식이나 공개 방식을 바꿀 때 |
| A-005 | AI는 OpenAI 호환 인터페이스를 사용한다. 키는 `OPENAI_API_KEY`, 모델은 `OPENAI_MODEL` 환경변수로 받고 모델 기본값을 코드에 고정하지 않는다. | 모델 교체를 코드 변경과 분리하고 비밀을 GitHub Secrets로 관리한다. 키가 없으면 파일 생성·커밋 없이 설정 검증까지만 허용한다. | 사용할 제공자와 모델을 확정할 때 |
| A-006 | 한 실행의 결과는 전부 성공해야 반영한다. 일시적 외부 API 오류만 최대 2회 재시도하고, 실패 단계와 대상은 Actions 로그와 실행 요약에 남긴다. | 부분 커밋과 중복을 막고 재실행으로 복구할 수 있다. | 부분 성공을 허용해야 할 때 |
| A-007 | 자동 테스트는 노션·AI·GitHub 경계를 모의 처리한다. 실제 자격증명이 제공되지 않으면 실제 API 및 커밋 검증은 완료되지 않은 통합 검증으로 남긴다. | 비밀 없이도 로직을 검증하되 외부 연동 성공을 과장하지 않는다. | 테스트 DB·branch와 자격증명이 제공될 때 |
| A-008 | 구현은 Python 3.12 단일 패키지로 하고 `python -m study_quiz`를 공통 진입점으로 사용한다. | 작은 자동화 프로젝트에 필요한 코드와 테스트를 단순하게 유지한다. | 저장소에 다른 런타임 제약이나 기존 구현이 생길 때 |

## 미결 항목

- 실제 노션 DB ID, 속성명/값 및 API 토큰
- 실제 AI 제공자, 모델명 및 API 키
- 외부 연동 검증에 사용할 GitHub branch와 테스트 권한

이 값들은 로컬 로직과 모의 통합 테스트 구현을 막지 않지만, 실제 외부 연동을 완료로 검증하려면 필요하다.
