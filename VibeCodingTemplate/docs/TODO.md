# MVP 구현 체크리스트

## 완료 요약

- 필수 구현 완료: Python CLI, 노션 조회·Markdown 변환, 멱등 동기화와 충돌 감지, 근거 기반 퀴즈 생성, 오류 보고, 두 수동 GitHub Actions 워크플로가 연결되어 있다.
- 모의 통합 검증 완료: 신규·수정·중복 실행, pagination, 빈 session, 사용자 수정 충돌, 일시·영구 API 오류, 잘못된 AI 응답, 다른 session 보존, 변경·무변경 커밋 조건을 자동 테스트한다.

## 남은 통합 검증

- [ ] 깨끗한 Python 3.12 환경에서 설치와 전체 검사를 실행한다.
  - 완료 조건: `python -m pip install .`, `make test`, `make check`, 두 CLI의 `--help`가 모두 성공한다.
  - 현재 차단 조건: 현재 작업 환경에는 Python 3.9와 3.11만 있으며, 패키지 빌드와 전체 검사는 Python 3.9 호환 실행으로 검증했다. GitHub Actions는 Python 3.12를 사용하도록 구성되어 있다.

- [ ] 제공된 외부 테스트 환경에서 실제 연동을 검증한다.
  - 완료 조건: 테스트 branch에서 신규 글, 수정 글, 중복 동기화, 빈 session, AI/API 실패를 실행한다.
  - 완료 조건: 성공 실행은 기대한 Markdown과 퀴즈 두 파일을 커밋하고, 실패 실행은 커밋하지 않는다.
  - 현재 차단 조건: 테스트 노션 database, `NOTION_TOKEN`, `OPENAI_API_KEY`, `OPENAI_MODEL`, GitHub Actions 쓰기 권한이 제공되지 않았다. 또한 현재 작업 폴더는 상위 Git 저장소의 미추적 하위 폴더이므로 workflow를 실행하려면 이 폴더의 내용을 실제 저장소 루트에 배치하고 커밋해야 한다.

## 후순위

- 자동 일정 실행 또는 노션 내부 버튼/별도 웹 UI
- 노션에서 삭제·비공개 처리된 글의 저장소 자동 삭제
- 이미지·첨부파일 다운로드와 저장소 보관
- 4지선다 외 문제 형식, 난이도 선택, 문제 수 사용자 설정
- 여러 AI 제공자별 전용 어댑터와 모델별 최적화
