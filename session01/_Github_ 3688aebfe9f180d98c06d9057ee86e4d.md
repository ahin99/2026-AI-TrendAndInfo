# _Github_

- 새롭게 깃 연결방법
    1. git init → 깃 초기화
    2. git add . → 파일 추가
    3. git commit -m “ “ → 커밋
    4. git remote add origin 레포주소 → 레포 연결
    5. git remote -v → 지금 어떤 레포랑 연결되어 있는지 확인
    6. git push -u origin main → 첫 푸시일때. 이후는 git push만.
- 깃 push 과정에서 오류나서 add, commit 한거를 취소하고 싶을때
    
    git reset --mixed HEAD~1 → 현재 파일 수정 내용은 유지함
    
- 깃 레포와 폴더 연결 끊기
    
    rm -rf .git → 이렇게 하고 다시 깃 연결하기
    
- 깃 브랜치 만들기
    1. git branch → 현재 브랜치 확인
    2. git switch -c (브랜치 이름)→ 새 브랜치 생성 및 이동 
    3. git branch → 다시 브랜치 확인
    4. 똑같이 add, commit
    5. git push -u origin (브랜치 이름) → 처음 push할때.
    git push → 이후에는 간단히 가능.
    6. 깃허브 들어가서 Compare & pull request 클릭, main으로 PR 생성
- 깃 zip으로 다운 말고, 저장소 연결 유지하면서 clone 하기
    
    git clone 레포주소(링크).git
